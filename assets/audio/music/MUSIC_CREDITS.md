Every screen now picks at random from a pool, with the previously-played track
excluded so the same song never plays twice in a row: map ×4, combat ×4 per
act, elite ×3, boss ×2 (acts 1–2; act 3 keeps its fixed heavyweight), rest ×3,
event/wayside ×3, shop ×2, menu ×2. `AudioBank.play_music` also remembers each
track's playback position and resumes there when the track re-enters rotation,
so intros don't wear out.

## Swapping tracks

To replace any track, drop a new `.ogg` / `.mp3` / `.wav` into this folder with
the same filename (the part before the extension is what `AudioBank.play_music()`
matches on). Loop seams matter — pick "seamlessly looping" tracks where you can.

## Format notes

Godot supports all three formats. OGG Vorbis is preferred for music (smaller
than WAV, no patent concerns unlike MP3). To convert with ffmpeg:

```
ffmpeg -i input.mp3 -c:a libvorbis -q:a 5 output.ogg
```
