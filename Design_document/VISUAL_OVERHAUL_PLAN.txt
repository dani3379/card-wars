BURNING MEADOW — Visual Overhaul Plan
=======================================

Current state: flat colored rectangles, tiny text, no visual hierarchy.
Everything is dark grey on dark grey. Looks like a prototype, not a game.

Goal: proper card game quality visuals using only Godot UI nodes (StyleBoxFlat,
Labels, ColorRects, Containers). No particle effects, no shaders, no imported
art assets. Just clean, well-structured programmatic UI.

PHASE 1: Card2D Redesign
==========================

Current: 140x200 flat dark rectangle. Cost and name on same line in tiny text.
Small colored rectangle as art. Stats at bottom center with "/" separator.
Keywords in yellow text. Everything cramped.

Target: Recognizable card game card. Clear visual hierarchy.

Card size: 160x220 (up from 140x200)

Layout (top to bottom):
  +----------------------------------+
  | [COST]  Card Name           [R]  |  <- Header bar (28px)
  |  (18)   (14pt ivory)      (gem)  |
  +----------------------------------+
  |                                  |
  |         ART REGION               |  <- 55% of card height
  |       (colored rect with         |
  |        inner frame border)       |
  |                                  |
  +----------------------------------+
  |  Keywords  |  Floop indicator    |  <- Keyword bar (16px, if any)
  +----------------------------------+
  |  Description text (11pt)         |  <- Desc area (fills remaining)
  |  wrapping, cream colored         |
  +----------------------------------+
  | [ATK]                     [HP]   |  <- Stat footer (30px, creatures)
  | red circle    or    green circle |
  |   (22pt)        "SPELL" (spells) |
  +----------------------------------+

Cost badge:
  - Circle shape (ColorRect + corner_radius = 14, size 28x28)
  - Blue fill (MANA_BLUE)
  - White number centered (18pt)
  - Always top-left, overlapping the header slightly

Name:
  - 14pt, IVORY color
  - Clip if too long
  - Left-aligned next to cost

Rarity indicator:
  - Small circle (8x8) or colored dot in top-right of header
  - Grey = starter, white = common, blue = uncommon, gold = rare
  - Subtle but visible

Art region:
  - Colored rectangle based on card ID hash (keep current approach)
  - BUT with higher saturation (0.55 player, 0.40 enemy) and value (0.45/0.30)
  - Inner border: 1px darker shade inset by 3px, creating a "frame" effect
  - For spells: use a different pattern — vertical gradient from spell_purple to darker

Keyword bar:
  - Only shown if card has keywords
  - Small text (10pt), GILT color
  - If floop: show small blue circle icon before "Floop"

Description:
  - 11pt, CREAM color
  - Auto-wrap
  - If no description (Peasant/Soldier), this area is smaller and art region grows

Stat footer (creatures):
  - ATK: left-aligned, red background circle (24x24), white number (20pt)
  - HP: right-aligned, green background circle (24x24), white number (20pt)
  - No "/" separator — the circles make it clear
  - Buffed ATK: circle turns yellow-gold
  - Damaged HP: circle turns darker red

Stat footer (spells):
  - "SPELL" centered, purple text (14pt)

Border:
  - 3px width (up from 2px)
  - 8px corner radius (up from 6px)
  - Default: PARCHMENT_BORDER
  - Hover: GILT (bright gold)
  - Flooped: MANA_BLUE
  - Sacrifice target: BLOOD_RED
  - Can't afford: border dims to FADED

Card background:
  - Creatures: dark warm brown (0.14, 0.11, 0.08)
  - Spells: dark purple-brown (0.12, 0.08, 0.14)
  - Enemy creatures: dark red-brown (0.16, 0.08, 0.06)
  - Slightly lighter than current — more contrast with the border

Floop on battlefield:
  - Available (not toggled): faint blue tint on border, small "floop" hint text
  - Toggled on: full blue border, art region gets blue-tinted overlay,
    "FLOOP" text replaces description area

Hover behavior (hand cards):
  - Lift up 40px
  - Scale to 1.15x
  - z_index = 10
  - Border changes to bright gold
  - On mouse exit: return to position (let container manage)

Unplayable (not enough mana):
  - Entire card gets 40% opacity overlay
  - Cost badge turns red instead of blue
  - Still draggable (game shows "not enough mana" message)

Files touched: Card2D.gd (rewrite _build_style, _build_layout, update_stat_display,
update_floop_display), may reference Theme.gd constants


PHASE 2: Combat Board
=======================

Current: flat black background, invisible lanes, tiny side labels, thin gold
midline, lane slots are barely visible panels with "Lane X" text.

Target: clear battlefield grid where you can see the 4-lane structure.

Background:
  - Not flat black. Gradient effect using two overlapping ColorRects:
    Top half: dark red-brown (0.12, 0.07, 0.06) — enemy territory
    Bottom half: dark green-brown (0.07, 0.10, 0.06) — player territory
  - Very subtle, just enough to distinguish sides without looking at labels

Lane columns:
  - Alternating very subtle tint: lanes 1 and 3 slightly lighter (+0.02 value)
  - Creates a visible 4-column grid without explicit divider lines

Lane slots:
  - Larger: 180px wide minimum (up from 150)
  - Empty slot appearance: card-shaped outline with dashed/faint border
    (1px, FADED color), rounded corners matching card shape
  - Remove "Lane 1/2/3/4" text — the card-shaped placeholders make it obvious
  - Slot background: very subtle fill (0.08, 0.07, 0.06, 0.3) — barely visible
    but distinct from the board background

Midline:
  - 4px thick (up from 3)
  - GILT color with slight glow (shadow_size = 3)
  - No labels — clean divider

Side labels:
  - Remove "— ENEMY SIDE —" and "— YOUR SIDE —"
  - The HP panels, card colors, and board gradient make it obvious
  - Less visual clutter

Lane spacing:
  - 12px between lanes (up from 8)
  - More breathing room for cards

Files touched: Combat.gd (_build_board, _make_lane_slot)

PHASE 4: Hand Area
===================

Current: HBoxContainer with -20 separation, cards in flat row, cards fly to
wrong position on hover/drag cancel.

Target: card fan with hover lift, clear hand region.

Hand region:
  - Defined area at bottom of board (between board and bottom HUD bar)
  - Very subtle dark panel backing (slightly darker than board bg)
  - 220px height for the hand area

Card fan layout:
  - KEEP HBoxContainer approach but improve it:
  - Separation: -30px (more overlap for larger cards)
  - Each card gets slight rotation: -(N/2 - i) * 2 degrees
    where N = hand size, i = card index
  - Each card gets slight Y offset: parabolic curve, center cards higher
  - This creates a natural fan/arc shape

Hover behavior:
  - Hovered card: lift up 40px (negative Y offset), scale 1.15x, z_index 10
  - Snap back on mouse exit via container re-sort
  - No position tracking needed — container manages base positions

Card count:
  - Small label in top-right of hand region: "Hand 4/10" (10pt, FADED)

Unplayable dimming:
  - Cards where cost > player_mana:
  - Apply modulate = Color(0.5, 0.5, 0.5, 0.8) to dim them
  - Cost badge turns red to show "can't afford"
  - Updated each time mana changes

Drag feedback:
  - While dragging above play threshold: card border glows green
  - While dragging below threshold: border returns to normal
  - On cancel: container re-sorts, card slides back

Files touched: Card2D.gd (hover behavior, fan rotation),
Combat.gd (_hand_container setup, draw_one for dimming updates)


PHASE 5: Map View
==================

Current: color-coded rectangular buttons, straight Line2D connections,
basic layout.

Target: map that looks like a journey/adventure path.

Node styling:
  - Replace plain buttons with styled circular nodes (60x60)
  - Each node type gets a distinct color AND icon text:
    Combat: dark red circle, sword icon text
    Elite: gold circle, star icon text
    Boss: large dark red circle (80x80), skull icon text
    Rest: green circle, campfire icon text
    Shop: amber circle, coin icon text
    Event: purple circle, "?" text

  - Available (clickable): pulsing border (brighter gold, use a timer to
    alternate border color), larger size
  - Current position: bright gold filled circle marker on current row
  - Visited: dimmed (40% opacity), small checkmark overlaid
  - Locked (not reachable): very dim (20% opacity), no border

  - Available paths: GILT color, full opacity
  - Visited paths: FADED color, 40% opacity

    slightly, end) for gentle S-curves between rows

Background:

  - Very subtle vertical "road" feel

Act banner:
  - Top of screen: "ACT 1" in large styled banner
  - Parchment panel with gold border, centered
  - Act number prominent (28pt)

Player info bar:
  - Bottom of screen: HP, gold, deck size, relics
