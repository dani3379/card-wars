# Burning Meadow — Midjourney Prompts (All 29 Missing Creatures)

## HOW TO USE

1. Paste each prompt into Midjourney
2. Pick the best of the 4 results (U1-U4 to upscale)
3. Download, rename to the **filename** listed, drop in `assets/creatures/`
4. Claude can batch-resize and strip metadata for you when you're done

## STYLE LOCK WORKFLOW

Generate **Prompt #1 (e_warden_champ)** first. If you like the result:
1. Copy the image URL
2. Add `--sref [paste URL here]` to ALL remaining prompts
3. This locks the visual style across all 29 cards

## SETTINGS FOR ALL PROMPTS

All prompts already include `--ar 3:2 --s 250` at the end.
- `--ar 3:2` = landscape ratio matching your card art window
- `--s 250` = moderate stylization (painterly, not photographic)
- `--no` = things to exclude

If results are too photorealistic, increase to `--s 500`.
If results are too abstract/artistic, decrease to `--s 100`.

## TROUBLESHOOTING

**Too photorealistic?** Increase `--s` to 500, or add "oil painting, painterly brushwork" to the prompt.

**Too dark / unreadable?** Add "bright subject, high contrast, well-lit face" to the prompt.

**Wrong framing (too wide)?** Add "extreme close-up, tight crop, head and shoulders only" to the prompt.

**Face looks weird?** Re-roll (hit the refresh button). MJ V6+ handles faces well but occasionally misses.

**Want more consistency?** After you like your first result, copy its image URL and add `--sref [URL]` to every remaining prompt.

**Subject too small in frame?** Add "macro portrait, subject fills entire frame" to the prompt.
